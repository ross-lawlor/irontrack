# IronTrack

A personal workout tracker that runs entirely in the browser — log sets, routines, PRs and progress charts.

**Open:** https://ross-lawlor.github.io/irontrack/

On iPhone, open the link in Safari, tap **Share → Add to Home Screen**. It then launches full screen and works offline.

Workout data is stored only on the device (browser storage). Use **Settings → Export backup file** to keep a copy.
